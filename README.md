# Brightwave Proclean

Responsive storefront for Brightwave Proclean.

## Included
- Home, About, What We Do and Contact sections
- 25 sample cleaning and janitorial products with starter prices
- Product search and category filters
- Shopping cart and order-enquiry preparation
- Browser-local price editor

## Run
Open `index.html` in a browser, or enable GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Before accepting real orders
This is a front-end starter shop. It does not process card payments or transmit orders to a store. Configure the business email/contact details, actual product catalogue, shipping and returns policies, and integrate a merchant payment provider before launch. The current price editor saves changes only in the browser where they are made; it is not a secure multi-user admin system. Replace the starter admin password in `index.html` and implement server-side authentication before public deployment.

Product names, descriptions and prices are illustrative sample content and must be checked against the actual Brightwave catalogue.
