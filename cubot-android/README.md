# CUBOT Android app

Android WebView app for the official CUBOT website. It retains the live website's original product photography, banners, navigation and pages. A small in-app text patch translates common Chinese navigation labels to English.

The app requires an internet connection because product pages and images are loaded from https://cubot.net/. It does not copy or redistribute the website's image files.

## Build
Open this folder as an Android Gradle project, or use the repository-root Codemagic workflow. Package: net.cubot.mobile.
